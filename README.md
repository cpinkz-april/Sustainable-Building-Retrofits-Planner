# Sustainable Building Retrofits Planner
An executive-level decision support dashboard built with Streamlit and Plotly to screen and prioritize building portfolios for energy efficiency retrofits and Scope 2 emissions reduction.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://sustainable-building-retrofits-planner.streamlit.app)

Descriptions:
- Engineered a Streamlit and Plotly executive dashboard to prioritize building retrofits, leveraging area size and age data to isolate high-priority pre-1990 properties for HVAC investments.
- Analyzed asset portfolios with Pandas to benchmark footprint against building age, identifying Education and Office facilities (30+ years old) as primary intervention targets.
- Designed a strategic framework and action plan for a 30-day pilot, aiming for 10–15% energy intensity reduction, Scope 2 emissions abatement, and a 24–36 month payback period.
